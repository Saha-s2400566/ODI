# ODI — Navigate your network

This workspace contains a starter Expo + TypeScript scaffold for the ODI mobile app.

Quick start

1. Install dependencies:

```bash
npm install
```

2. Start Expo:

```bash
npm start
```

Open with Expo Go (Android/iOS) or run on simulator.

Notes
- The project targets Expo SDK 54 and React Native 0.81.5 as requested.
- Networking scanner is a safe stub using `expo-network` for local info; full LAN scanning requires platform-specific network probes and explicit permissions.
