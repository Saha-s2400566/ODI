# ODI Development Guide\n\nThis guide explains ODI's architecture, key patterns, and how to extend the app.\n\n## Project Overview\n\nODI is a **React Native + Expo** mobile app built with **TypeScript** and **Context API** for state management.\n\n**Core Purpose**: Three reliable network diagnostic tools + persistent storage + educational content.\n\n**Key Principle**: Simplicity and honesty over complexity and simulation.\n\n---\n\n## Directory Structure\n\n```\nODI/\n├── src/\n│   ├── screens/              # 11 screen components\n│   │   ├── HomeScreen.tsx\n│   │   ├── ToolsIndexScreen.tsx\n│   │   ├── ReachabilityScreen.tsx\n│   │   ├── DnsLookupScreen.tsx\n│   │   ├── PortCheckScreen.tsx\n│   │   ├── SavedResultsScreen.tsx\n│   │   ├── SaveResultDetailScreen.tsx\n│   │   ├── SubnetCalculatorScreen.tsx\n│   │   ├── IpConverterScreen.tsx\n│   │   ├── LearningHubScreen.tsx\n│   │   ├── SettingsScreen.tsx\n│   │   └── AboutScreen.tsx\n│   │\n│   ├── services/\n│   │   └── diagnostics.ts        # 3 tool implementations\n│   │       ├── checkReachability()\n│   │       ├── performDnsLookup()\n│   │       └── checkPort()\n│   │\n│   ├── context/\n│   │   ├── ThemeContext.tsx       # Dark/light mode + persistence\n│   │   └── SavedResultsContext.tsx # Diagnostic history + AsyncStorage\n│   │\n│   ├── navigation/\n│   │   └── index.tsx              # Tab + stack navigation structure\n│   │\n│   └── utils/\n│       └── ip.ts                  # IP math (CIDR, subnet, masks)\n│\n├── App.tsx                        # Root with providers\n├── app.json                       # Expo config\n├── package.json                   # Dependencies\n├── tsconfig.json                  # TypeScript config\n└── README.md\n```\n\n---\n\n## Key Patterns\n\n### 1. Context API for Global State\n\n**ThemeContext** (dark/light mode)\n```typescript\nconst { theme, setTheme, isDark } = useTheme();\n```\n\n**SavedResultsContext** (diagnostic history)\n```typescript\nconst { results, addResult, removeResult, getResult } = useSavedResults();\n```\n\nBoth are wrapped in App.tsx:\n```typescript\n<ThemeProvider>\n  <SavedResultsProvider>\n    <MainNavigator />\n  </SavedResultsProvider>\n</ThemeProvider>\n```\n\n### 2. AsyncStorage Persistence\n\nData is persisted under storage keys:\n- `@odi_theme` → Theme preference\n- `@odi_saved_results` → Diagnostic history\n\n**Pattern**:\n```typescript\nconst STORAGE_KEY = '@odi_saved_results';\n\n// Load on mount\nuseEffect(() => {\n  AsyncStorage.getItem(STORAGE_KEY).then(stored => {\n    if (stored) setResults(JSON.parse(stored));\n  });\n}, []);\n\n// Save on change\nconst updateResults = async (newData) => {\n  setResults(newData);\n  await AsyncStorage.setItem(STORAGE_KEY, JSON.stringify(newData));\n};\n```\n\n### 3. Navigation Structure\n\n**Bottom Tabs** (4 main sections)\n```\nHome → Quick tool shortcuts\nTools → Tool index + individual screens\nSaved → Persistent result history\nMore → Calculators, learning, settings\n```\n\n**Stack Navigation** (Tools & More)\n```typescript\nconst ToolsStack = createNativeStackNavigator<ToolsStackParamList>();\n\n<ToolsStack.Screen name=\"ToolsList\" component={ToolsIndexScreen} />\n<ToolsStack.Screen name=\"Reachability\" component={ReachabilityScreen} />\n<ToolsStack.Screen name=\"DnsLookup\" component={DnsLookupScreen} />\n<ToolsStack.Screen name=\"PortCheck\" component={PortCheckScreen} />\n```\n\n### 4. Diagnostic Services\n\nAll three tools are in `services/diagnostics.ts`:\n\n```typescript\n// Reachability\nexport async function checkReachability(target: string, port = 80): Promise<ReachabilityResult> {\n  // Tries HTTP/HTTPS on different ports/protocols\n  // Returns: { target, reachable, status, responseTime, method }\n}\n\n// DNS\nexport async function performDnsLookup(hostname: string): Promise<DnsResult> {\n  // Uses Google DNS API\n  // Returns: { hostname, ipv4[], ipv6[], error? }\n}\n\n// Port\nexport async function checkPort(host: string, port: number): Promise<PortCheckResult> {\n  // Attempts HTTP connection to host:port\n  // Returns: { host, port, open, responseTime, service? }\n}\n```\n\n---\n\n## Screen Patterns\n\n### Tool Screens (Reachability, DNS, Port)\n\n**Layout**:\n1. Input card (TextInput + Button)\n2. Result card (appears after running tool)\n3. Save button (persists to AsyncStorage)\n\n**State Flow**:\n```typescript\n[user enters target]\n  ↓\n[user taps button]\n  ↓\n[setLoading(true)]\n  ↓\n[call service function]\n  ↓\n[setResult(response)]\n  ↓\n[display result card]\n  ↓\n[user can save → addResult()]\n```\n\n### Saved Results Screen\n\n**Pattern**: FlatList + Context\n```typescript\nconst { results, removeResult } = useSavedResults();\n\n<FlatList\n  data={results}\n  renderItem={({ item }) => (\n    <TouchableOpacity onPress={() => handleViewDetail(item.id)}>\n      {/* Result card */}\n    </TouchableOpacity>\n  )}\n/>\n```\n\n### Detail Screen (Result View)\n\n**Pattern**: Route params + Context lookup\n```typescript\ntype Props = NativeStackScreenProps<{ SaveResultDetail: { resultId: string } }, 'SaveResultDetail'>;\n\nconst { resultId } = route.params;\nconst { getResult } = useSavedResults();\nconst result = getResult(resultId);\n```\n\n---\n\n## Styling\n\n**Color Solutions\n\n### Issue: App crashes on DNS lookup\n**Cause**: Google DNS API down or blocked  \n**Solution**: Add fallback, show error message\n```typescript\nexport async function performDnsLookup(hostname: string) {\n  try {\n    const response = await fetch(...);\n    // ...\n  } catch (error) {\n    return {\n      hostname,\n      ipv4: [],\n      ipv6: [],\n      error: `Failed to resolve ${hostname}`,\n    };\n  }\n}\n```\n\n### Issue: Saved results disappear after app restart\n**Cause**: AsyncStorage not initialized, or loading before context provider  \n**Solution**: Ensure SavedResultsProvider wraps app\n```typescript\n// App.tsx\n<SavedResultsProvider>\n  <MainNavigator />\n</SavedResultsProvider>\n```\n\n### Issue: Theme not persisting\n**Cause**: AsyncStorage write fails silently  \n**Solution**: Add error logging\n```typescript\nconst setTheme = (t: Theme) => {\n  setThemeState(t);\n  AsyncStorage.setItem(STORAGE_KEY, t).catch(err => {\n    console.warn('Theme save failed:', err);\n  });\n};\n```\n\n### Issue: Metro server won't start\n**Solution**\n```bash\n# Clear cache and restart\nnpm start -- --clear\n\n# Or use different port\nnpm start -- --port 8081\n```\n\n---\n\n## Performance Tips\n\n1. **Lazy load screens**: React Navigation does this automatically\n2. **Memoize expensive functions**: Use `useMemo()` for subnet calculations\n3. **Debounce text input**: Avoid rapid API calls\n4. **Limit FlatList data**: Show pagination or virtualization if >100 results\n\n---\n\n## Deployment
